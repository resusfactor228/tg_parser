# CRM Telegram Parser

Локальный парсер участников Telegram-групп. Заходит в ваш аккаунт через MTProto API и собирает информацию об участниках непубличных групп: имена, никнеймы, телефоны, bio.

## Требования

- Python 3.10+
- Аккаунт Telegram
- API ключи с [my.telegram.org/apps](https://my.telegram.org/apps)

## Установка

```bash
git clone <repo>
cd CRM_tg_parse
pip install -r requirements.txt
```

## Использование

```bash
python main.py
```

При первом запуске программа спросит API_ID и API_HASH — они сохранятся в `session/config.json` и больше не понадобятся. Затем предложит выбрать способ входа:

```
Метод входа: [1] QR-код  [2] Номер телефона →
```

**Вход по QR-коду (рекомендуется):** откройте Telegram → Настройки → Устройства → Подключить устройство и отсканируйте QR-код из терминала. Если QR истёк — генерируется новый автоматически.

**Вход по номеру телефона:** программа спросит номер, Telegram пришлёт код подтверждения в приложение.

После авторизации сессия сохраняется в `session/` — повторные запуски не требуют входа.

**Сценарий работы:**
1. Программа покажет таблицу всех ваших групп
2. Выберите группы для парсинга (`1,3,5` или `all`)
3. Выберите, собирать ли bio (медленно: ~2 сек/человек)
4. Результат сохранится в `output/`

## Что собирается

| Поле | Описание |
|------|----------|
| `user_id` | Telegram ID пользователя |
| `first_name` / `last_name` | Имя и фамилия |
| `username` | Никнейм (@handle) |
| `phone` | Телефон (если не скрыт настройками приватности) |
| `bio` | Описание профиля (опционально, медленно) |
| `is_bot` / `is_deleted` | Служебные флаги |

## Формат вывода

Файлы создаются в папке `output/`:

```
output/
  название_группы_<id>.csv
  название_группы_<id>.json
```

При повторном запуске bio подгружается только для новых участников — уже скачанные пропускаются.

## Безопасность

- `session/` и `output/` добавлены в `.gitignore` и не попадут в репозиторий
- `session/config.json` содержит API ключи, `session/user.session` — авторизацию. Не публикуйте эту папку
